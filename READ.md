 Node.js CI/CD Project with Jenkins and AWS EC2

A basic Node.js app with automated deployment using Jenkins on AWS EC2.

  Features
- Node.js + Express
- Jenkins pipeline for CI/CD
- Deployment on AWS EC2
- PM2 for process management

  Setup
1. Clone this repo
2. Run `npm install`
3. Run `npm start` or `pm2 start index.js`

 Technologies Used
- Node.js
- Jenkins
- AWS EC2
- PM2
